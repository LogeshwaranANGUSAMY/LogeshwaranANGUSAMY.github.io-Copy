# Logeshwaran Angusamy — bilingual resume website

## Preview locally
1. Extract this ZIP.
2. Open `index.html` in a modern browser.

## Publish online
- GitHub Pages: upload the contents of this folder to a repository, then enable Pages in repository Settings.
- Netlify or Vercel: deploy this folder as a static website.

## Before publishing
- Check that the contact details are the ones you want to make public.
- The full street address from the CV has intentionally not been displayed; the site says Germany instead.
- The download button currently provides the English CV only. Add a reviewed German CV PDF before changing its label.
- Check all project descriptions and add direct repository/demo links only where the code and evidence are ready to show recruiters.
- This is a static website; the contact section uses email/phone/social links and does not submit a form.
